# 字幕翻译生成 · CaptionCraft 0.6.0

这版采用 Chrome 插件 + 一次安装的 Windows 字幕助手。普通用户不需要安装 Python、输入命令、粘贴令牌或打开 Start.cmd。

安装测试：
1. 双击 CaptionCraft-Assistant-Setup-v0.6.0.exe，点击安装。扩展 ID 已填好，通常不要修改。
2. 全部解压 CaptionCraft-Extension-v0.6.0.zip 到长期保留的目录。
3. Chrome 打开 chrome://extensions，开启开发者模式，加载解压后的文件夹（里面直接有 manifest.json）。旧版插件先关闭，避免重复字幕。
4. 刷新 YouTube 视频，打开新插件。助手会自动启动，首次等待模型下载。然后点击生成字幕。

当前是商店发布前的测试版，所以仍需手动加载扩展。正式商店版才能直接点击商店安装；还未上架。测试版的稳定 ID 见 EXTENSION-ID.txt，换文件夹不改变 ID。以后商店分配 ID 后，安装器需要随之更新。

不必运行旧版 Start.cmd。新助手不使用旧版端口或令牌。可从已知旧安装目录自动复制模型以避免重复下载；如果旧目录被移动，会自动下载所需模型。升级会保留新助手的 Data 目录，程序使用独立版本目录。旧 ZIP 可以删除，Chrome 加载的扩展文件夹必须保留。旧安装目录确认不再需要后可另行清理。

助手自动连接并在约五分钟没有服务请求时退出。完成的同步字幕继续在网页中显示；下一次使用自动启动。首次或新增翻译方向仍需网络下载模型，有进度提示；下载之后本地识别和已有翻译方向可离线使用，但在线视频获取仍需要网络。重启 Chrome/电脑后无需手动开启助手。

六种原文：英语、日语、法语、西班牙语、韩语、俄语。翻译目标额外包含中文。可仅原文、双语或仅译文；七种设置界面。字体/背景/透明度/拖动/SRT 导出保留。实时备用目前只显示原文并有延迟。

优先已有原文字幕，否则先下载音频再分段生成。还未做到网络流式下载识别。未准备片段会暂停，就绪后自行播放。获取失败可导入本地音频。视频最多三小时、导入最多 200 MB；不绕过登录、付费或 DRM。识别错字和翻译误译仍可能发生。

建议 Windows 10/11 64 位、8 GB 内存及数 GB 空间。无需 NVIDIA 显卡。安装包内置 Python、依赖和 Deno，所以比以前 ZIP 大得多；不包含模型权重。助手安装到当前用户目录，无需管理员权限。

出错：展开更多选项，重新连接助手；也可查看助手日志。首次下载超时可检查网络后重试。升级插件后刷新视频页面。模型下载时间因网络和 CPU 而异，不保证固定等待时间。

卸载：先退出 Chrome，在 Windows 设置→应用中卸载 CaptionCraft Assistant。可选择同时删除模型和字幕缓存。默认保留数据。程序目录在 %LOCALAPPDATA%/CaptionCraft/app-0.6.0，数据在 %LOCALAPPDATA%/CaptionCraft/Data。卸载器本身是小型程序，不会删除其他软件。

未来扩展：shared/languages.json 集中定义源语言、目标语言和显示名称，构建时生成前端语言列表；界面文案、模型可用性、翻译路线和测试仍需对应更新。增加语言无需让用户重新安装 Python，但新增模型首次仍需下载。不要仅添加语言代码就宣称模型支持。

测试版安装器尚未做发行签名，Windows 可能显示未知发布者。真实 Chrome Native Messaging 注册/连接、安装/卸载 UI、干净 Windows 机器兼容性仍需验收，见 TEST-REPORT.md。发行前需代码签名、各模型许可检查及商店审核；不会自动发布到 GitHub 或商店。
